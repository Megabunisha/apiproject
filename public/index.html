📖 REST Endpoints Specification

Method Endpoint Description Status Code Payload
GET /posts Retrieve all blog posts (supports ?search, ?category, ?sort) 200 OK None
GET /posts/:id Retrieve a single blog post by unique ID 200 OK / 404 None
POST /posts Create a new blog post with title, content, author, category 201 Created / 400 JSON Object
PUT /posts/:id Update an existing blog post by ID 200 OK / 404 / 400 JSON Object
DELETE /posts/:id Delete a blog post by ID 200 OK / 404 None
